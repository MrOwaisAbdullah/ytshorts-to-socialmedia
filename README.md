# YouTube Shorts to Social Media Syndicator

A Streamlit web application designed to repurpose YouTube Shorts into formatted, engaging multi-platform social media posts (LinkedIn, Twitter/X, Facebook).

## 🚀 Key Features
- **Transcript Extraction**: Automatically pulls video subtitles and transcripts.
- **AI Formatting**: Restructures short-form video scripts into engaging written social posts.
- **Streamlit Interface**: Clean, intuitive web dashboard.

## 🛠️ Tech Stack
- **Language**: Python 3.12+
- **UI Framework**: Streamlit
- **Tooling**: uv
